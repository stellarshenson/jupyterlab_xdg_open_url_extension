2. **Task - Terminal xdg-open to notification** (v0.1.0): Implemented the core feature - a terminal `xdg-open` becomes a JupyterLab notification with an Open button<br>
   **Result**: The `jlab-xdg-open` console script (`jupyterlab_xdg_open_url_extension/shim.py`) prints an invisible OSC escape `ESC ] 6789 ; <url> BEL`. The frontend (`src/index.ts`) listens to every terminal via `ITerminalTracker` + `session.messageReceived`, reassembles the marker across output chunks (`src/osc.ts`, jest-tested), and POSTs to `jupyterlab_notifications_extension` `/ingest` with `immediate: true` (the `--now` flag) plus an Open action whose `commandId` runs `window.open`. Removed the redundant server extension (`routes.py`, `jupyter-config/server-config`, server hooks in `__init__.py`/`pyproject.toml`); added the notifications extension as a runtime dependency and `@jupyterlab/terminal` + `@jupyterlab/apputils` to `package.json`. Pending `make build` and live verification.

3. **Task - Switch Open action to help:open** (v0.1.3): Replaced the notification's custom Open command with the built-in `help:open` after the original was popup-blocked<br>
   **Result**: The first Open action ran a custom `jlab-xdg-open:open` command calling `window.open(url, '_blank', 'noopener,noreferrer')`; the feature-string form made the browser treat it as a popup and block it. Switched `src/index.ts` to the built-in `help:open` command with args `{url, text, newBrowserTab: true}`, which opens a real browser tab via a bare `window.open` that survives the click gesture, and removed the now-unused custom command. Built and installed at v0.1.3 via `make install` (TypeScript compiles, wheel builds); OSC parser jest suite green (7/7). Supersedes the `window.open` detail in entry 2.

4. **Task - Transparent xdg-open shadow + callback replay** (v0.1.5): Made the emitter intercept tools that spawn `xdg-open` (e.g. claude login) and added a headless OAuth callback replay<br>
   **Result**: Added a second `[project.scripts]` entry `xdg-open` -> `shim:main`, so `pip install` drops an `xdg-open` into the env bin dir ahead of `/usr/bin` - a real PATH shadow (a shell alias cannot work; child processes spawned by `claude`/`gh` never see aliases). `shim.py` now writes the OSC marker to `/dev/tty` (falling back to stdout) so it reaches the JupyterLab PTY even when the caller discards the child's stdout. Added `jlab-xdg-open --callback <url>` - a serviceless one-shot GET delivering the OAuth code to the login tool's own short-lived `localhost:PORT` server, restricted to loopback and not following redirects (verified against a local 302 server). Documented token/paste-code/replay login paths in the README.
